FAQ

Everything important, upfront.

What does legal cybersecurity mean here?

The catalog is limited to defensive uses such as privacy, endpoint protection, backup, recovery, security awareness and compliance-oriented services.

Can the shop become a real checkout?

Yes. The cart, checkout state, order summary and local persistence are already separated from presentation so a backend or payment provider can be connected later without rewriting the storefront.

How do GitHub lessons work?

A public repository is configured in the app module. Its issues are fetched client-side; pull requests are filtered out, issue images are detected from Markdown and the remaining content is shown as learning cards.

Are the prices real?

The included catalog is a demo dataset. Replace the data module with your actual SKUs, prices, inventory and vendor metadata before launch.
